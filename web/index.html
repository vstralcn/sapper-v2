全局上下文

    
统一填写服务器信息、本机环境、工具和使用约定。适用于本 Web 服务管理的各工作区与角色，不修改用户全局 Claude 设置。

    

    
    
    
注入方式
      
      
    

    
这里填写的文本不会作为 shell 脚本执行。启动提示词已提供同一版本时，hook 不重复输出该文本；启用 hooks 后，运行中会话在后续消息时读取更新；仅启用启动提示词时需新建或恢复会话。保存不代表模型已采用，角色面板会显示启动版本及最近 hook 检查版本。

    
关闭后停止后续注入，已进入会话历史的内容会保留。SSH 认证继续使用原环境配置。
