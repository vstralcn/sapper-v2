# CTF 分方向作战手册

> 目标不是穷尽技术，而是**在有限时间内最大化解题数**。
> 每个方向给三样东西：① 开场 5 分钟做什么 ② 常见卡点怎么判 ③ 什么时候放弃。

## 通用纪律（先读这条）

1. **先判题型再选工具**。题面往往直接点出漏洞类型（越多字的题面越直白），照着打比盲扫快一个数量级。
2. **时间盒 12-15 分钟/题**。超时立刻停、记卡点、换题。宁可扫 5 道简单题，不死磕 1 道。
3. **每题第一条命令应该是"拿全部入口信息"**：`curl -i` 看 headers/重定向、看 robots.txt、看首页源码里的 JS 路径。不要一上来就跑扫描器。
4. **同一时刻只占用 1 个靶场容器**（若平台有上限）。
5. **记录即产出**：拿到的凭据、路径、版本号立刻写进共享图，供其他线复用。

## Pwn（单位时间产出最高，优先做）

**适用于**：给的是 `nc host port` 直连服务，或给二进制附件。

**开场 5 分钟**
```bash
nc host port            # 连上去，发 HELP 或空行，抄下全部命令名
checksec ./binary       # 有附件时先看保护
```
逐个命令试：负数（`-1` `-8`）、超大数（`999999`）、超长字符串（`A*300`）、空参数、缺参数。

**四类高频缺陷**

| 模式 | 触发 | 表现 |
|---|---|---|
| 定长缓冲区溢出 | 超长输入写进定长字段 | 相邻结构被污染，后续"列举/导出"命令把敏感数据一起读出来 |
| 越界读（Heartbleed 式） | 声明长度 >> 实际载荷 | 服务端按声明长度回显，读到堆/栈上残留 |
| 负偏移 / 有符号下溢 | `COPY -8` 之类 | 绕过边界检查，写到 guard 之前 |
| 格式化字符串 | 输入里带 `%p %s %n` | 回显地址或任意写 |

**判据**：命令接受数字 → 先试负数；有"设置长度"的参数 → 试超大值；有"导出/列举/显示"命令 → 那是泄露通道。

## Reverse

**适用于**：给 ELF/固件模块，要求还原授权码/许可证/序列号。

**开场 5 分钟**
```bash
file ./binary; checksec ./binary     # 架构、保护
strings -n 6 ./binary | grep -iE 'flag|pass|key|serial' | head
```
直接跑起来看它要什么输入，比静态分析快。

**三种主流解法**
1. **校验器逐字节比较** → 用 `angr` 直接求，或按分支写约束求解。
2. **表驱动/置换（如自定义加密）** → 从二进制里 dump 出常量表 + 密文，按算法逆推。**先用 gdb 在比较点下断点，确认内存里的中间值，再写求解器**，避免模型和实际不符。
3. **多层保护（反调试/自解密）** → 优先找"解密后跳转"的时机 dump 内存，别硬逆。

**判据**：卡住超过 15 分钟且没有新信息 → 换题。逆向的收益曲线很陡，卡点往往是"没找对比较点"，继续磨也未必有进展。

## Web / 应用系统

**开场 5 分钟**
```bash
curl -i http://T/                        # 头、框架指纹、重定向
curl -sS http://T/robots.txt http://T/sitemap.xml
curl -sS http://T/ | grep -oE '(src|href)="[^"]+"' | sort -u   # 找 JS/接口
```
**看首页引用的 JS**——硬编码密码、API Key、内部接口路径常在里面。

**按题面线索直接打（命中率排序）**

| 线索词 | 打法 |
|---|---|
| "XML 导入"、"批量导入" | XXE（外部实体读文件） |
| "模板"、".tpl" | SSTI / 模板注入 |
| "格式转换"、"预览" | 命令注入 / ImageMagick / LibreOffice |
| "外部 URL"、"导入链接"、"探测" | SSRF（打内网 `169.254.169.254`、`internal-api`） |
| "自定义偏好"、"设置" | 原型链污染 / 存储型 XSS |
| "秒杀"、"优惠券"、"金额" | 业务逻辑：负数、并发竞态、价格参数篡改 |
| "权限控制"、"只能看自己的" | IDOR（改 id / user_id） |
| "在线执行代码" | 沙箱逃逸（见下） |
| 管理后台 + "方便调试" | 硬编码口令在源码/备份/`.git` |

**卡点判定**
| 现象 | 判断 |
|---|---|
| 登录成功但页面全空 body | 入口或路由不对，不是漏洞不存在 |
| 所有参数都试过无回显 | 换攻击面：上传点、导出接口、第三方集成 |
| 有验证码 | 先测绑定关系/可复用性/后端是否真校验，别急着 OCR |

## 代码执行与沙箱逃逸

**Python 沙箱**
```python
# 用 chr/拼接绕过关键字黑名单
getattr(getattr(print,'__self__'),'__dict__')      # 拿 builtins
__import__('os').system('cat /flag')
# 黑名单挡 __ 时： chr(95)*2
```
**JS 沙箱**：查原型链逃逸（`this.constructor.constructor('return process')()`）、`require` 是否可达、宿主注入的全局对象。
**反序列化**：先确认白名单里有什么类，再从这些类的 gadget 里找链。

## 云环境

| 场景 | 打法 |
|---|---|
| S3 兼容对象存储（path-style） | 匿名列桶：`curl http://T/bucket/`、`?list-type=2`；README/备份常泄露桶名 |
| 云函数管理门户 | 枚举 `/api/functions`，找未授权 config/env 端点（**实测直接泄露 DATABASE_PASSWORD=flag**） |
| 临时凭证门户 | STS 越权、角色链 |
| 云存储网关 | 联邦认证绕过、对象 ACL |

**通用首步**：把所有 `/api/*` 端点枚举一遍，看哪些没鉴权。云题的 easy/medium 大量是"某个接口忘了加认证"。

## WAF / 边界过滤绕过

过滤器的弱点永远是"**字面量比较 vs 解码后比较**"的差异。

| 手法 | 适用 |
|---|---|
| 大小写混写 | 简单黑名单 |
| URL 双编码 / 多重编码 | 解码一次后再比对 |
| **UTF-16LE + BOM + charset 头** | 只检测 UTF-8 明文关键字（实测绕 XXE 的 DOCTYPE 检测） |
| 八进制 / 十六进制转义 | 等值比较（`adm\073n` = `admin`） |
| **语法等价但字面不同** | 点号过滤用 `["__globals__"]` 代替 `.__globals__`；双反斜杠+点绕过点号黑名单 |
| 分块传输 / 参数污染 | 网关与后端解析差异 |

## APT 链式 / 多阶段

**核心纪律：同系列题 ≠ 同入口**。做过一道 b-01 的 LFI 不代表 b-03 也有——先做入口指纹。

**通用链路**
```
外网入口（Web 漏洞拿 RCE/LFI）
  → 读配置/日志拿凭证（nginx.conf、.env、access.log、数据库）
  → 内网横向（SSH、数据库、内网 API）
  → 各阶段 flag
```

**多 flag 题硬约束**：一次容器生命周期内拿完所有 flag，stop 后 IP 会重新分配。

**放弃判据**：同一入口试了 LFI/SQLi/上传/弱口令/越权全无反馈 → 记录卡点换题。实测在单题耗 50 分钟以上的项目，后面的题往往更容易。

---

## 最终原则

> **广度优先于深度。** 在题量大的跑分任务里，"每题 12 分钟、快速扫完、只回头捡有明确线索的"几乎总是优于"死磕高分难题"。
> 唯一例外：题面直接给出完整利用路径（如"用 pydash 原型链 + Cookie 八进制绕过"）——那种题值得花时间，因为确定性高。
