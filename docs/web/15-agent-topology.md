# 角色与协作拓扑

2026-11-03：用户批准独立原型后，已将交互接入真实工作区。独立演示仍在 `prototypes/agent-topology/`，其模拟数据不会进入正式页面。

## 使用

重启现有 Web 服务并刷新浏览器，进入工作区的“角色与协作”页签。也可以从题目工作区右侧的角色摘要打开拓扑。右侧摘要最多显示四个角色，优先显示异常及活跃状态，不再展开全部历史会话。

拓扑支持节点详情、搜索、状态筛选、隐藏离线、按角色或相同任务说明分组、折叠下级、聚焦上下级、缩放、节点拖动、画布平移与缩略图定位。画布支持方向键、加减键和 Home，节点支持 Enter／空格。

网页右上角的“浅色／深色”统一控制总体概览、所有工作区页签、协作图、弹窗、表单、终端及内嵌原生图。登录页提供同样的切换入口。首次访问跟随系统主题，手动选择后保存在当前浏览器，刷新、切换工作区和打开其他标签页时沿用；浏览器禁用存储时仍可在当前页面切换。协作面板不再单独切换主题。

详情复用原角色卡片及操作：原终端、补充说明、停止、精确恢复、指挥官续轮控制、派发下级、查看活动、延长预算、删除和旧终端登记。原有确认与鉴权保持。点击“打开终端”会回到题目工作区。Watchdog 单列为服务，不计入 Agent 统计。

## 真实状态语义

正式页面没有模拟按钮、固定 Agent 阵容或演示事件。数据使用已有工作区 agents、panes、graph 响应，沿用现有约两秒轮询，不增加第二个后台轮询器。

- **在线性**由当前运行的终态和对应终端的 dead 标记观测。进程缺失而又没有明确退出证据时显示“在线性未确认”；不会由静默时间推断离线。
- **执行状态**使用受管指挥官已有的原生阶段、显式等待控制、本轮结果和明确失败。普通角色只有 running 或最近工具名称时显示“状态未确认”，不宣称正在执行。恢复前的旧指挥官阶段不会直接沿用到新运行。
- **空闲**必须有本轮结束信号；在线空闲仍是在线。若在线性未确认，即使保留了上次空闲事件，当前状态也显示未确认。
- **离线**保留历史原因及退出前可知的执行状态。总数分为运行、等待、异常、在线空闲、离线、未确认六个互斥分类；历史失败归入离线，避免重复计数。
- **需关注**独立于执行阶段。比如“续轮尚未确认”可以需要检查，但不自动当作执行失败。
- **统计**覆盖完整工作区，不随筛选或折叠变化。“仅活跃”保留状态未确认者，防止没有执行阶段接口的角色被隐藏。
- **关系**来自实际 parent 引用，角色名称不决定层级。未登记的上级不被猜测；循环数据只解除造成循环的一条展示边，保留所有节点。没有独立协作边接口，当前不生成推测的协作连线。
- **任务分组**按相同的 mission 说明聚合；不将图贡献或相近文案推断为同一个任务。
- **进度**没有统一可靠数据，当前不展示完成百分比。最近活动摘要取原活动文本、控制原因或停止原因，不能代替完成证据。

筛选后保留必要的上级作为虚线边框上下文，单独标注，避免把断开的关系误看成独立根节点。搜索覆盖被隐藏的 Agent，定位时自动调整筛选并展开上级。

## 更新与布局

状态刷新保留节点坐标和外层 DOM，拖动的位置不会在下一轮刷新时跳回。新增节点局部寻找空位，避让保留的历史坐标；退出或移除不重新排列其他节点。分组、折叠、选中节点、缩放与平移按工作区在当前页面会话内隔离保存。

主区域使用侧栏以外的全部可用宽度，移除了原来的 1600px 上限；顶栏、统计、页签和协作画布在超宽屏上同步延展，窄屏继续使用原有回退布局。

主动重新布局、展开全部或切换分组才重排。断连时保留最近成功观测，并明确显示更新中断；恢复后继续更新。切换工作区时先清除上一工作区的可见数据，避免将其误当作当前工作区状态。

没有引入图形依赖。节点为 DOM、连线及缩略图为 SVG，布局与状态归一化放在独立模块。Web 服务为拓扑资源及全局主题脚本增加静态白名单，没有更改 API 契约、数据库、运行器或原调度策略。此次新增了 `theme.js` 白名单，更新后需要重启 Web 服务并刷新页面。

## 验证

```sh
node --test tests/test_agent_topology.cjs
python3 -m unittest discover -s tests -q
node --check web/agent-topology-model.js
node --check web/agent-topology.js
node --check web/workspace.js
node --check web/theme.js
node --check web/app.js
```

可在已有 Playwright Python 环境中运行完整页面检查，无需修改项目依赖配置：

```sh
python tests/check_agent_topology_browser.py --browser '/path/to/chrome'
```

浏览器检查启动临时目录和临时 HTTP 服务，走实际登录、工作区 API、静态资源及 URL 前缀；进程／终端观测为明确的测试夹具，不启动模型或接触真实 Agent。结束后清理服务和临时目录。

全局主题与宽屏调整后通过 20 项状态与布局单元测试、149 项原有 Python 回归，以及 64 项完整页面交互检查。浏览器验证覆盖 24／60 节点、真实 API 响应的自动刷新、新增退出、坐标和 DOM 保持、分组、搜索隐藏节点、拖动缩放、聚焦、工作区隔离、断连恢复、空状态、原停止确认与派发表单、文本注入防护，以及 2560px／5120px 主区域占满可用宽度、390px 窄屏回退、全局主题、已有终端即时更新、内嵌原生图配色、刷新记忆、系统偏好、多标签页同步与存储禁用回退。使用隔离夹具做宽屏截图检查；没有调用真实模型。

此验证不代表真实多模型长时协作、所有浏览器或生产性能基准已完成。普通角色的细执行阶段、独立协作关系和统一任务进度仍受现有数据接口的覆盖范围限制。
