# 角色与协作：第一阶段独立原型

入口：[index.html](./index.html)。双击后在现代浏览器打开即可使用，也可以将文件拖入浏览器。CSS、JavaScript、图标与模拟数据全部内嵌，无需安装依赖或联网。

如需 HTTP 预览，在项目根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototypes/agent-topology
```

然后打开 `http://127.0.0.1:8765`。按 Ctrl+C 停止预览服务。

## 范围

仅新增本目录的独立原型与说明。没有修改现有业务代码、API、数据库或依赖配置，没有正式集成。页面不调用工作区接口，不启动模型、终端或真实 Agent。所有任务、状态、协作、日志、时间和检查点均为模拟数据。

## 交互设计

- **先关注当前运行。** 初始为“仅活跃”，显示运行、等待和异常；两个分支初始折叠。默认异常节点的详情打开。顶栏异常入口可定位需要关注的 Agent。
- **在线性与执行状态分离。** “活跃优先”包含在线空闲，隐藏离线；“仅活跃”排除空闲；“显示全部”包含离线。离线节点的详情保留退出前的执行状态。统计按运行、等待、异常、在线空闲、离线互斥计数，始终覆盖完整数据集。
- **由记录生成结构。** 派发实线来自模拟 parent 引用，协作虚线来自显式模拟关系。示例包含独立根节点、验证者派发执行者、多层下级；没有按角色名称假定父子关系。
- **节点承载概要，右侧承载证据。** 节点展示名称、角色、在线性、执行状态与任务摘要；详情展示完整任务、活动时间、上下级、协作、日志和显式检查点。不提供时间推算的完成百分比。
- **稳定更新。** 状态变化更新节点内容；新增节点在父节点附近查找空位，保留其他节点坐标。退出不删除历史坐标。筛选保留必要上级作为虚线边框的上下文，并单独标注上下文数量。视图切换、展开全部和主动重新布局才重新组织全图。
- **规模控制。** 24 个 Agent 为默认数据；下方可切换 60 个 Agent。支持按角色、任务聚合与展开；折叠后的连线映射到分组，详情仍对应具体 Agent。聚焦使无关节点变淡，不擅自改写关系。
- **可直接操作。** 点击节点、搜索所有 Agent（包含被隐藏的历史节点）、滚轮缩放、拖动空白平移、拖动节点调整、缩略图定位、适应画布与主题切换均可使用。画布支持方向键、加减键及 Home；节点和折叠按钮支持键盘。
- **适度动态。** 自动演示默认关闭，每 5 秒执行一次模拟事件，可随时暂停；新节点只有一次短暂强调，尊重 reduced-motion。没有持续流动的连线或无意义的节点闪烁。

此原型使用原生 DOM、SVG、CSS 和 JavaScript。图组件选型、真实接口适配、生产性能与生命周期边界测试留在明确批准后的集成阶段。

## 建议评审路径

1. 在默认视图中阅读分工和异常原因；展开两个分支，观察细节密度。
2. 切到“活跃优先”，确认灰蓝色空闲节点仍标记在线；再“显示全部”查看半透明离线节点。
3. 搜索 `a24`，定位原来被折叠隐藏的离线节点；查看退出前状态与任务。
4. 选中一个在线节点，用底部控制切换状态、添加下级、退出和重新上线；观察统计与关系同步变化。
5. 拖动一个节点后切换状态，确认位置保留；使用“重新布局”主动整理。
6. 切到 60 个 Agent，尝试按角色或任务折叠、聚焦、缩略图和平移缩放。
7. 选择“文件处理”节点查看模拟检查点；其他无检查点节点不展示虚构进度。

## 本轮验证

2026-11-03，使用本机 Chrome 的 headless 模式完成 47 项浏览器交互断言：

- 完整数据统计、默认过滤、在线空闲与离线区分；
- 四种执行状态转换、退出与重新上线、日志更新；
- 新增真实父引用与多层关系，新增和状态刷新保留已有坐标；
- 点击、搜索隐藏节点、聚焦与退出聚焦、分组展开；
- 节点拖动、画布平移、按钮与滚轮缩放、键盘平移；
- 60 节点展开完整性、自动布局无节点卡片重叠；
- 深色样式变量、说明和事件弹窗、自动演示与暂停；
- 1100px 桌面与 390px 窄屏无页面横向溢出；
- 无浏览器脚本异常，无工作区或远程数据请求。

另外检查 JavaScript 语法、直接通过 `file://` 打开的离线交互，以及原型文件的空白格式。只做了一次浅色完整页面截图进行布局检查。上述验证针对独立模拟原型，不代表真实状态接入、生产性能、所有浏览器、完整可访问性或用户评审已经完成。
